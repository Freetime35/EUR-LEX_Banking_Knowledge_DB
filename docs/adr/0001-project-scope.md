# ADR 0001 — Périmètre du projet

## Statut
Accepté.

## Décision
Le projet construit une base de connaissances européenne spécialisée dans la réglementation bancaire et financière.

Le catalogue précède le téléchargement massif. Les identifiants CELEX, ELI et Cellar, les relations juridiques et les classifications sont prioritaires.
